STUDIO NIKO / GUIDE INTÉGRÉ

Niko-Ultravision

Restauration et super-résolution locale d'images et de vidéos.

Premiers pas

  1. Déposez une image ou vidéo dans la zone d'import.
  2. Choisissez Canvas pour un rééchantillonnage fidèle ou un modèle ONNX pour une super-résolution IA.
  3. Vérifiez l'aperçu et les détails générés avant d'exporter le résultat.

Avant de commencer

Prévoyez de l'espace mémoire et vérifiez l'état de votre projet avant fermeture.

Le mode IA peut nécessiter le chargement d'un grand modèle, WebGPU ou WASM ; il peut introduire de faux détails.

En cas de problème

En cas de page vide ou d'erreur : rechargez une fois, vérifiez la connexion et les permissions ; sur une PWA déjà installée, fermez-la puis rouvrez-la pour actualiser son cache. Consultez le dépôt GitHub si le problème persiste.
